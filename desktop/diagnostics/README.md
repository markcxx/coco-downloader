# 历史诊断记录

本目录的 JSON 文件记录 2026-10-11 对当时版本进行的渠道探测、Web 播放、完整下载及打包验证，供排查历史问题参考。

这些记录不代表当前代码的验证结果，也不保证渠道现在在线。桌面端目前仅提供搜索下载，历史报告中涉及的桌面播放结果不适用于当前版本；Web 仍保留播放功能。

当前单元测试与构建命令见 [根目录 README](../../README.md#验证) 和 [桌面文档](../README.md#验证)。需要重新检查渠道时，使用 [当前探测脚本](../tools/README.md#渠道联网探测)，将新结果写入 `desktop/build/`，避免覆盖历史报告。
